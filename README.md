# Orbital portfolio

React portfolio inspired by the supplied floating-card reference.

## Run locally

Run `npm install`, then `npm run dev`. Use `npm run build` for a production build.

## Files

- `src/App.jsx`: page sections, sample project data, filters, and accessible project dialogs.
- `src/App.css`: neutral colors, orbital graphics, card positions, and mobile layout.
- `src/main.jsx`: React entry point.
- `backups/original-template-2026-10-28/`: untouched original template, including all assets. Open its index.html to view the previous design.

Names, descriptions, images, and contact copy are placeholders. Images come from the original template; replace them with your own work before publishing.
